# このレポジトリの開発計画

## このレポジトリについて

このレポジトリは、製造業DXの経験を示すポートフォリオとして開発する。
利用する外部パッケージとして、`manufacturing-data-generator`がある。
これも自身で開発したものだが、本レポジトリではこのパッケージ自体の改修は行わない。

## 開発目標

開発の目標は、自身の技術力を示すことであるため、
単にチュートリアルをなぞっただけでは不十分。

下記の技術要素をプロダクションレベルで扱う能力があることを示す。

- docker composeによるPostgreSQL/dbt/Supersetの環境構築
- stagingレイヤーの構築(データクリーニング)
- intermediateレイヤーの構築(業務プロセスの紐付け)
- martsレイヤーの構築(データ粒度の整理, 履歴管理の実装)
- dbt testsの実装
- 実行時の負荷の把握
- 定期実行の実装(Prefect)
- KPI定義
- Kimballの理解
    - Factless factの実装
    - Accumulating factの実装
- ダッシュボードの構築
